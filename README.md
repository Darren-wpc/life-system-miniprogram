# 人生系统小程序

基于《生活系统与人生系统：框架详解》的微信小程序，将框架从纸面诊断工具升级为持续运行的个人生活操作系统。

## 快速开始

1. 打开**微信开发者工具**
2. 选择「导入项目」，目录指向 `life-system-miniprogram`
3. 将 `project.config.json` 中的 `appid` 替换为你自己的小程序 AppID
4. 点击编译即可预览

## 核心公式

```
活得好 ≈ 合适的标准 × 持续行动 × 资源支持 × 反馈修正 × 接受不确定性
```

乘法关系意味着任何一项接近零，整体就接近零。小程序帮用户识别瓶颈因子并提供针对性工具。

## 功能模块

| Tab | 名称 | 路径 | 核心功能 |
|-----|------|------|----------|
| 1 | 首页 | `pages/index` | 六维雷达仪表盘、崩溃点/杠杆点/失衡点智能诊断 |
| 2 | 评估 | `pages/assess/weekly` | 周级六维自评、五因子乘积计算器、七类资源盘点 |
| 3 | 反馈 | `pages/feedback/daily` | 日级睡前一句话、季级四类结构复盘 |
| 4 | 工具 | `pages/toolkit/notodo` | 不做清单、底线设定、取舍汇率、中断脚本、不可控清单、重启剧本 |
| 5 | 我的 | `pages/profile/narrative` | 叙事一致性三问、转向判据六信号监测 |

## 六维健康度框架

| 维度 | 关注点 |
|------|--------|
| 生存基础 | 健康、安全、睡眠、饮食、住处、基本收入 |
| 自主权 | 时间是否属于自己，能否拒绝，能否选择 |
| 能力资产 | 可迁移技能、学习新东西的能力、积累而非消耗 |
| 关系支持 | 可信任连接的质量，而不是数量 |
| 内在秩序 | 情绪、价值观、自我接纳、独处能力 |
| 意义贡献 | 价值连接、创造、承担、人生值得感 |

## 项目结构

```
life-system-miniprogram/
├── app.js / app.json / app.wxss
├── assets/               Tab 图标
├── utils/
│   ├── db.js            本地存储管理（8类数据 CRUD）
│   ├── constants.js     六维/五因子/七资源/转向信号等常量
│   └── diagnosis.js     崩溃点/杠杆点/失衡点/瓶颈识别算法
└── pages/
    ├── index/           六维仪表盘首页
    ├── assess/           评估（周评/五因子/资源）
    ├── feedback/         反馈（日级/季级）
    ├── toolkit/          工具箱（6个工具）
    └── profile/          我的（叙事/转向）
```

## 数据存储

所有数据使用微信小程序本地存储（`wx.setStorageSync`），不上传云端。

| 数据类型 | 存储键 | 隐私级别 |
|----------|--------|----------|
| 六维周评 | `ls_weekly_scores` | 高 |
| 五因子评分 | `ls_factor_scores` | 高 |
| 资源盘点 | `ls_resources` | 高 |
| 日级反馈 | `ls_daily_feedback` | 高 |
| 季级复盘 | `ls_quarterly_review` | 高 |
| 工具内容 | `ls_tool_*` | 极高 |
| 叙事记录 | `ls_narrative` | 最高 |
| 转向判据 | `ls_pivot` | 高 |
